## 录制准备

1. 提前打开银行端，评估企业选“恒岳联合钢铁”，从正常情景开始。录制时等待计算完成再切镜，后台等待与重复滚动剪去；旁白和录屏分别录制，再按时间表剪辑。
2. 审核镜头可直接使用当前已结案的企业A历史案例，展示已有说明与审核记录。若要展示“银行核验结论”的可编辑处理方式，需要另行准备“待银行审核”的演示任务；本剧本不要求为录制实际提交核验结论。
3. 全程保留“模拟数据·辅助决策”小角标。旁白中的82.6%、16%→31%、3,512→3,341万元来自当前企业A演示案例。RAROC画面保留“演示门槛”字样。

## 与策划书及当前网页的对应

- 参考《工银碳跃智衡 商业策划书》第三部分产品与业务模式、第四部分算法体系和完整平台实现例，采用企业A的达标概率、天然气压力情景与融资额度案例。
- 按当前网页四个银行端入口组织画面。“园区风险分析”已包含压力情景，不另设独立压力测试镜头。
- 减排归因使用当前网页的瀑布图与结论。策划书旧段落的减排百分比与当前模拟台账存在差异，因此旁白不混用这些百分比。
- 业务依赖图箭头表示依赖方指向被依赖方；风险图箭头表示影响方指向受影响方。画面随所选视图保持一致。
- 企业分组、关键链路精简仅影响显示；风险汇总、授信建议仍采用完整计算结果。SHAP说明模型贡献，审核任务触发人工核验，不直接认定企业造假。
