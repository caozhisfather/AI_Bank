# 园区模拟主体与依赖数据重建方案

本方案将现有36个图谱主体重构为以钢铁产业链为主、建材资源利用为配套的园区关联网络。目标是让主体名称、实际业务、依赖方向、压力响应和企业A的策划书演示相互对应。本文件是待实施方案，本次不修改企业记录、历史版本或网站功能。

所有建议名称均为演示拟名，不声明对应真实注册企业或已发生的交易。内部ID用于数据关联，图谱和企业选择器显示业务名称，不再使用带序号的企业名称。园外供应商、客户在网络中标注“园外”，不计入园内入驻企业数。

## 现有数据的主要问题

- 36家企业均被设为钢铁或水泥，各18家；P01至P30按奇偶交替生成，缺少业务角色。
- 原始关系69条，其中有效分类53条，另16条共享能源或物流记录因方向不明确暂未计入。能源关系全部由水泥企业D发出，公共设施关系由P01、P05、P09等生产企业发出，未提供相应供给能力。
- A目前从水泥企业F以及P26采购的设定，没有具体商品支持；不能通过改名保留所有旧边。
- 能耗、项目、资金、行业标签与名称分散在CSV和数据库版本中，只修改企业名称会造成其他记录继续显示旧行业或旧项目。
- 现有转型预测按同一特征模板处理全部企业，无法直接用于污水厂、配电运营方或贸易客户。

保留内部ID，重建名称、画像与关系。按主要业务分为12家钢铁及金属加工、6家原料与配套供应、5家下游客户、7家建材与资源利用、3家能源服务、3家公共设施服务，共36个关联主体。主体可以同时具有供应商和客户角色，不能把分类当作只能单向连接的限制。

这36个关联主体不等于策划书试点阶段30至50家转型画像客户。原型阶段优先展示完整产业链；进入该试点规模时再扩充主行业生产客户，不能把园外贸易方和设施节点凑入转型预测样本数。

## 企业A周边的具体业务结构

先构建A的一阶关系，再连接这些主体各自的真实业务上游或下游，最后扩展其余园区主体，不再按编号随机连成环。

| 业务 | 合理主体 | 需要记录的业务量 |
| --- | --- | --- |
| 焦炭采购 | 东港焦炭供应 | 采购吨数、金额、占同类采购比例、安全库存 |
| 矿石采购 | 海联矿石供应 | 矿石来源、吨数、替代供应周期 |
| 工业气体 | 联益工业气体 | 氧氮气用量、管道或储供方式、备用保障 |
| 天然气 | 清源天然气供应 | A的供气量、气价、合同传导、备用燃料 |
| 电力 | 江海园区配电 | 购电量、峰值负荷、保障和切换能力 |
| 水与污水 | 清润供水、清澄污水处理 | 供水量、排水量、回用量、处理余量、停运容忍时长 |
| 钢材销售 | 远达轧钢、适配的机械和钢结构客户 | 产品匹配、销售占比、回款期限、客户替代难度 |
| 副产品利用 | 中辰矿渣微粉、绿源钢渣资源化 | 高炉矿渣或钢渣各自的产生、交付和处理量 |
| 余热利用 | 江海集中供热 | 确有可回收余热时的热量、可用率与外供合同 |

A仍为长流程钢铁案例。天然气可以作用于轧制加热等工序，不能设成直接替代全部焦炭或把A改为依赖天然气炼铁的企业。生产内部回用煤气应与外购天然气分别记账。

三类图谱关系保留采购/销售、能源、公共设施。采购边写明具体原料或产品；能源边区分天然气、电、蒸汽；设施边区分供水、污水处理、固废处置。工业氧氮气作为生产投入供应，不因名称含“气”归入燃气能源依赖。资源化材料购买属于采购，付费处置属于设施服务，不因同一对主体发生多种业务而混用。

业务图保持“依赖方 → 被依赖方”，风险图保持“影响方 → 受影响方”。例如A依赖燃气公司，业务箭头为A→清源燃气，风险箭头为清源燃气→A；A依赖核心客户订单，则业务箭头为A→客户，风险箭头为客户→A。采购依赖与销售依赖可以形成双向风险，但必须分开记录分母与经济机制。

风险传入示例：配电运营方→污水处理→A，核心客户→轧钢客户→A。风险传出示例：A→远达轧钢→钢结构客户。示例链须在重建数据中明确写入关系、强度和机制后才能出现在图上。

## 数据构建方法

### 主体和设施

统一主体表记录entity_id、名称、行业细分、园内或园外、业务角色、供给商品或服务、工艺路线、风险模板、融资评估资格、来源和版本。设施有独立facility_id及operator_id，避免同一公司经营多个设施时重复计授信。数字ID仅内部使用；节点显示“清源燃气”“清澄污水”等短名称及角色标签。

生产客户进入适配的转型评价模板；能源与公共设施首先进入运行风险模板；贸易和纯供应主体主要提供经营、订单或履约风险。没有适配行业模型时，不套用钢铁LightGBM输出转型达标概率，也不默认生成融资建议。各类节点的风险输入需明确时间窗口和含义，异质风险合成结果称综合风险指数，不宣称为经过真实校准的联合违约概率。

### 时间序列和业务平衡

按细分工艺生成至少12个月、推荐24个月的月度数据。先确定产能、开工率、产量、单位能耗和项目进度，再生成用能、现金流与资金支付。月份间保留季节性和项目投产变化，不对所有字段独立抽随机数。

钢铁区分吨钢、吨轧材、吨铸件，水泥区分熟料与水泥，供热使用GJ或吨蒸汽，水务使用立方米，配电使用kWh。单位、能源折算及排放因子分别记录，不能把不同能源的原始单位直接相加。进出水、废渣去向、能源购入和供出均检查平衡及损耗。

转型特征尽量由原始数据派生：碳强度趋势来自历史产量与排放，能效和结构贡献来自LMDI，项目进度来自项目台账，资金一致率来自支付和用途，自有资金到位率来自实际与计划投入。若A的既有特征定义与页面LMDI口径不同，须先统一期间、分母和符号，再重新校准，不能同时保留互相矛盾的数字。

用户已选择工艺效应仅采用可核验企业原始数据。因此本轮重建不虚构工艺过程原始记录来填空；缺少核验资料时仍显示未纳入核算，不以模拟零值或行业均值替代。其他新增模拟业务参数单独标识为模拟，不能借名称变真实而标为已核验。

### 关系和保障

关系记录两个主体、具体商品或服务、依赖类型、方向依据、报告期间、数量、金额、份额分母、关键性、替代周期、依赖强度、来源和核验状态。

- 采购以某类关键投入的供应份额衡量；销售以接收方对源客户的销售收入份额衡量；能源以对应能源供给份额和成本或工艺暴露衡量；设施以服务覆盖、必要性、替代和停运容忍衡量。
- 每类依赖的原始份额分别闭合，不能把采购、销售、能源份额相加后要求等于100%。同一关系的复合风险权重与原始份额分开保存。
- 供给量不得超过可用产能；同一批钢材采购与销售记录、矿渣产生与接收量相互对应；停供影响与库存天数相容。
- 备用能源、双路供电、库存、替代客户等缓释需有单独记录，按保障范围、可用率、切换时间及成本作用到对应关系。不把“接入公共设施”直接等同于负风险，也不让所有关系都产生缓释。

### 情景响应

天然气涨价影响实际用气企业及燃气供热运营方；电价主要影响电炉、粉磨、水处理等用电成本；核心客户需求下降通过订单依赖影响上游。影响强度由能源或收入暴露决定，不能对所有主体使用同一个冲击敏感度。

天然气价格上涨与物理供气中断分别建情景，不能默认涨价即停供。A的达标概率已经纳入的直接成本冲击，不再以额外直接冲击重复叠加；网络增量须解释为其他主体的经营、订单、履约变化或保障弱化，不能重复计入A同一笔用气成本。

## 策划书A案例的约束和校准

策划书规定主要演示结果，并未给出每家企业的名称、所有边权或一二阶缓释分项。以下聚合结果作为验收目标，拓扑和保障分项是本项目新增模拟设定。

| 指标 | 正常 | 天然气价格上涨30% |
| --- | --- | --- |
| A基础额度 | 3000万元 | 3000万元 |
| A项目需求 | 1000万元 | 1000万元 |
| 达标概率 | 82.6% | 74.0% |
| 数据可信度 | 95% | 95% |
| 自身未达标风险 | 约17.4% | 26.0% |
| 综合风险 | 16.0% | 31.0% |
| 一二阶净影响合计 | 约−1.4个百分点 | +5.0个百分点 |
| 转型支持 | 628万元 | 562万元 |
| 网络扣减 | 116万元 | 221万元 |
| 最终建议额度 | 3512万元 | 3341万元 |

正常一阶和二阶净影响不必机械固定为−1.2和−0.2，也不应强制每一阶都为负；按路径实际算出，合计与整体目标一致。综合风险公式保持既有的“自身风险＋一阶净影响＋二阶净影响，最后限制到0至1”，显式保障机制与风险传入分开记录。

先建立物理和交易上合理的A局部网络，再通过有限、可解释且限定范围的模拟参数校准两种情景。不得为凑16%或31%随意添加边、把权重变负或直接覆盖输出。若既定机制无法同时满足结果，应报告约束冲突并调整模拟假设，而非伪称模型自然推得。

核心算法文档另有A的LMDI示例：产量效应约+2千吨、能效约−9千吨、能源结构约−5千吨、净变化约−12千吨。当前A原始演示能耗并不直接对应这组绝对值。如纳入本轮统一，须按能源与产量约束重建月度模拟记录，统一基期和单位，由LMDI重新算得近似结果；工艺缺失仍保留。不可直接把页面文本改为上述结果，或把它们当作企业实测排放。

## 实施与验证顺序

1. 冻结并保存现有A案例、模型版本和历史记录，建立上述主体映射与业务画像。
2. 建立A的输入、输出、能源和公用服务链，再补齐关联主体；将旧循环生成边逐条停用或重建。
3. 生成相互一致的月度经营数据、项目资金台账、关系与保障参数，更新持久化版本和引用，不复用已结案记录代表新业务。
4. 为不同主体设置适配评估入口；能源和设施节点展示运行能力、服务对象和故障影响，未适配者不出现钢铁转型评分。
5. 校验方向、采购销售镜像、能源水务平衡、路径贡献和压力敏感性，再校准A案例并保留验收测试。
6. 检查选择器、图中短名称、详情、审核列表、导入模板、账户绑定和历史版本中的名称与身份一致；授信只按实际纳入的借款主体汇总，不人为保留原80116万元总额。
