# 银行端两分钟演示视频脚本

片名：同样减排12% 银行该支持谁

目标时长1分58秒，主讲人后期录制旁白，技术人员分段录制网页操作。以恒岳联合钢铁为主要融资案例，华新水泥用于减排来源对照，并在后续园区链路中作为下游企业再次出现。全片由一笔技改融资串联，依次回答支持谁、关联谁、如何承压、影响谁、如何调整额度、异常如何核验。

屏幕角标保留“模拟案例”。以下时间包含旁白、操作和画面停顿；不朗读操作说明。具体时长以配音和彩排为准。

## 录制前准备的数据与页面

关系图不是只靠企业名称生成。关系记录需要明确端点、商品或服务、依赖类型、份额或强度、报告期间、替代周期及来源，结合以下台账建立园区关联网络。

| 数据 | 需要呈现的主要信息 | 在视频中的作用 |
| --- | --- | --- |
| 企业主体名录 | 企业编号、名称、行业、业务角色、产品或服务、园内外属性 | 区分钢铁企业、供应商、下游客户、能源与公共设施主体 |
| 采购销售及业务流台账 | 供需双方、商品、期间、交易量、采购或销售依赖份额、替代周期 | 形成供应与客户依赖，定位一阶和二阶关系 |
| 能源供应与服务台账 | 燃气、电力、蒸汽等供给方和使用方、用量、能力与备用保障 | 识别共同能源依赖，分析价格压力与缓释变化 |
| 公共设施服务台账 | 供水、污水、一般固废等服务方与接收方、服务量、能力与保障 | 形成独立的公共设施依赖渠道 |
| 企业转型及融资评估数据 | 月度产量和分能源能耗、项目进度、资金用途、自有资金、经营现金流及基础授信 | 支撑归因、达标预测、异常任务和融资测算 |

当前关系数据已由模拟结构化台账接入项目。视频用字幕交代数据来源即可，不录制当前页面不存在的通用上传或一键抽取按钮，也不将尚未核验的模拟台账表述为真实银行已核验数据。

## 连贯性与录制要点

1. 开头只用两家企业对比；25秒后固定恒岳为主要分析对象。华新在下游链路中再次出现，是同一园区的关联企业，并非突然换了融资主角。
2. 归因对比是在比较减产式与改善型减排。华新减排贡献中减产占91.7%，不能把这个数说成产量下降91.7%；产量效应−11%也不是实际产量降幅。
3. 两种图的箭头不同：业务依赖图为依赖方→被依赖方，风险图为影响来源→受影响方。01:06的链路必须在风险传导视图录制。
4. 高风险成因分为企业自身承压、关联传入及缓释变化。使用正常与压力的风险分量对照和连线详情说明；不能声称网络图自动证明了全部经济因果。天然气涨价是成本压力，不能说成必然停供。
5. 当前“主要恶化企业”按风险增幅排名，并非按风险绝对值排名。恒岳是前三之一，不称其为园区风险最高的企业。保持恒岳分析对象，旁白与其风险、额度结果一致。
6. 风险传导默认“关键链路”只展示部分路径。若恒岳→中辰→华新未完整显示，录该段前切到“全部链路”，保留所需的一阶、二阶关系，再进行后期局部标注，不添加数据库不存在的箭头。
7. “不同企业、不同情景”用融资对照字幕说明即可，避免来回切换打断主线。公共设施和部分配套主体没有适配转型融资模型，不拿它们演示额度。
8. 合理异常核验结案与更正重算是两种处理方式。当前已有A历史案例为核验合理；不把它剪成数据更正案例，也不把历史审核动作当作当前压力情景产生的任务。
9. 不使用“保持征信”“自动修复征信”等旁白。平台支持的是核验说明、记录依据，并按适用版本处理数据质量评价；不直接修改外部征信记录，也不因产量下降自动认定企业造假。
10. 按8个镜头分别录屏，剪去加载和寻找按钮时间；固定浏览器尺寸、字号与鼠标速度。除开场对照外，一次只突出一个区域。关键数字停留约2秒，字幕不重复整段旁白。

## 核对记录

2026年10月26日从本地生效版本读取模拟数据重新计算：恒岳正常达标概率82.6%、综合风险16%、建议额度3,512万元；燃气压力下为74%、31%、3,341万元。华新正常与燃气压力的建议额度四舍五入为2,438与2,378万元。恒岳正常与压力RAROC分别为9.1%和8.5%。

燃气压力下，按综合风险增幅排列的前三为中辰矿渣微粉、恒岳联合钢铁、海筑装配式构件。风险网络含恒岳联合钢铁→中辰矿渣微粉→华新水泥二阶传导路径。已有A历史“数据组合异常”案例结论为核验合理，留有材料与审核记录。

录制前再核对一次当前生效版本，若数据已更新，以页面结果调整字幕；不为适配剧本修改模型输出。策划书中的算法分工通过短字幕点到即可：LMDI归因、LightGBM预测与SHAP解释、两阶网络传导、RAROC校验、异常识别与人工核验。
