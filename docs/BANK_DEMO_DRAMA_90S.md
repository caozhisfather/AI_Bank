# 工银碳跃智衡银行端双人演示剧本

剧名：这笔转型贷该怎么批

两位角色围绕企业A的一笔技改融资配合演示，在90秒内展示银行端的减排归因、达标预测、园区风险传导、压力情景联动、融资建议和人工核验。主讲人负责全部旁白、业务解释和观众引导；技术人员负责网页操作，全程无须对白。操作提示不朗读。

贯穿企业：恒岳联合钢铁。开场情景：正常情景。屏幕角标：企业A模拟案例。按90秒以内设计，旁白与操作同步进行，具体节奏以彩排计时为准。

## 演示准备与操作要点

1. 提前登录银行端，选定恒岳联合钢铁、正常情景，从评价页的归因图开始。浏览器缩放和窗口尺寸提前固定，确认滚动一次能到达SHAP区域。
2. 主讲人只负责旁白与手势引导，技术人员只负责操作，不需要解释模型。提前约定“归因图”“展开”“再看园区”“现在模拟”“融资建议”“审核任务”六个操作提示词，听到提示词即切换对应画面。
3. 正常情景的网络镜头保持企业A。先看真实业务依赖，再看风险传导；两张图箭头含义不同。业务依赖图为“依赖方→被依赖方”，风险图为“影响来源→受影响主体”，均不直接表示货物或付款方向。
4. 风险图使用“关键链路”，保留“全部”传播层级，同时看到传入与传出；不在短片里反复切一阶、二阶。现场需要解释时，再指出一阶是直接影响，二阶是经过一个中间主体的影响。
5. 天然气涨价是成本压力情景，不能演成天然气供应商必然停供。正常情景下园区净缓释约1.39个百分点；压力情景下净传入约5个百分点，综合风险从16%升至31%。两阶影响均按当前模型计算，不能把每条链路都说成减风险。
6. 压力情景下达标概率为74.0%，可作字幕展示，无须增加旁白。数字念完后留短暂停顿；正常17.4%→16%用于展示园区缓释机制，压力16%→31%与额度3,512→3,341万元用于展示联动结果。
7. 审核镜头提前准备已有记录；若使用“已结案”案例，保留历史版本标识。没有待审核任务时，展示已有说明、材料和审核历史即可，不把一次普通结案演成完成了数据更正。现场不需要提交审核结论，也不实际修改正式贷款合同。
8. 如果录制后剪辑，可剪去加载与寻找按钮的时间；若现场连续演示，提前完成一次全流程计时彩排。若切换卡顿，用对应步骤的录屏或截图接续，口播：“这里展示同一情景的预录结果，重点看风险路径和融资建议如何联动。”

## 与旧稿相比的重点

- 用主讲人叙述一笔技改融资，将“为什么减排、风险从哪来、影响谁、能贷多少、异常怎么核验”串为一笔业务；技术人员同步展示对应画面，不另设企业代表或业务人员对白。
- 把减排归因与SHAP解释、园区缓释与双向风险传导作为核心画面，压力测试成为触发它们联动的情节。
- 页面名称与现有银行端一致：转型可信度评价、园区风险分析、融资决策、审核任务清单。压力测试已在园区风险分析中，无需另找页面或点击“重新测算”。
- 不引用旧稿中的42家企业、6048条记录、90.5%准确率、0.867 AUC，也不安排当前不存在的园区驾驶舱、数据底座或系统验证入口。

## 数据与依据

2026年10月25日按当前项目输入重新计算企业A：正常情景达标概率约82.6%，自身风险约17.4%，一阶净影响约−1.70个百分点、二阶约+0.31个百分点，综合风险16%，建议额度3,512万元；天然气价格上涨30%后达标概率74%，自身风险26%，综合风险31%，建议额度3,341万元，预警橙色关注。正常与压力RAROC分别为9.1%和8.5%。这些均为模拟案例结果，不是实测企业或银行正式授信结论。

依据：本项目《工银碳跃智衡商业策划书》的真实减排识别、可解释达标预测、两阶网络传导、动态融资及人工核验设计；`data/reference_case_a.json`、`tests/test_reference_case.py`及当前银行端组件。减排百分比采用当前能源台账，工艺原始数据尚待补充。
