# 园区业务数据重构结果

已实施36主体模拟园区重构，包含钢铁及金属加工12家、原料及配套6家、下游制造与贸易5家、建材与资源利用7家、能源3家、公共设施3家。内部编号及账号绑定不变，页面使用业务名称和简称。海联矿石供应、江湾钢材贸易标注园外；关联主体数不等于园内入驻企业数或转型模型客户数。

## 业务和风险数据

101条业务关系均给出商品或服务、份额口径、关键性、替代周期、方向、来源和模拟状态。采购销售39条、能源37条、公共设施25条。旧69条按编号循环生成的关系不再参与本版计算；原始文件和数据库参考表已保存在备份及迁移记录中。

企业A采购焦炭、矿石、合金及耐材，使用工业气体、燃气、电力和水务服务，向轧钢及板材加工等主体供应钢材，并与矿渣、钢渣资源利用形成关联。工业氧氮气属于生产投入，不按天然气能源关系处理。钢铁副产余热单独标记，有模拟回收服务关系才连接供热主体。

所有新增名称与业务参数均为模拟，不声明真实注册身份或真实交易，也不标为银行已核验。工艺效应仍需可核验原始明细，未通过新增模拟工艺数据填空。

## 企业A案例

能源记录经LMDI计算得到产量效应约+2000吨、能效效应约−9000吨、能源结构效应约−5000吨，净变化约−12000吨；基期能源相关排放100000吨，净变化−12%。能效及能源结构减排份额从该记录派生，不直接填写模型结果。

正常达标概率约82.6%、数据质量95%、自身风险约17.4%、综合风险16%，融资支持628万元、扣减116万元、最终3512万元。天然气价格上涨30%后达标概率74%、自身风险26%、综合风险31%，融资支持562万元、扣减221万元、最终3341万元。

正常一阶净影响约−1.70个百分点，二阶约+0.31个百分点，合计约−1.39个百分点；压力下一阶约+4.63、二阶约+0.37，合计+5个百分点。各阶按路径计算，没有强制一二阶都为负，综合风险加法与截断公式不变。

燃气压力缓释参数采用“应急采购和保障预算受到燃气成本占用”的明确模拟假设：参考价格涨幅30%，保障保留程度随预算敏感度下降。该参数是为解释策划书演示结果的模拟机制，不等于燃气涨价自动导致物理停供，也不是经实证校准的行业系数。达标概率内的A直接成本冲击不重复作为额外直接风险叠加。其他情景使用各主体自己的敏感度，逆向树分裂造成的不合理概率改善由不利情景上限约束处理，SHAP保留原模型解释并单列情景调整。

综合风险为包含不同主体运行和转型影响的演示指数，不解释为经过真实违约样本校准的联合违约概率。未适配的能源、设施、供应和贸易主体返回空转型概率及空融资输出，显示运行画像；不以零概率或零融资额度冒充评估结果。

## 图谱展示

业务箭头保持依赖方指向被依赖方，风险箭头保持影响方指向受影响方。图谱仍保留园区总览、当前主体两阶关系、三类筛选及点击切换动画。

总览按原料、钢铁加工、下游、建材资源、能源及公共设施分区。局部图按一二阶分圈，并沿完整外圈分配二阶主体，避免公共来源的子节点挤在狭窄扇区。企业局部图和风险图按当前依赖类型、传播层级筛选后的完整链重新分配位置，风险图随节点列数调整高度；保留节点连续移动，移出节点淡出，新增节点淡入，画布高度同步过渡。快速连续筛选从当前动画帧接续，系统减少动态效果偏好下直接更新。总览始终保留分类分区和固定位置。连线在画布内选择避开节点和名称的曲率，平行渠道保留独立偏移；直接关系深色，背景关系浅色，悬停主体突出其连线，悬停连线显示业务与强度。所有关系均保留真实端点，视觉优化不合并风险权重或改箭头方向。

### 精简分组与压力重点

业务总览和局部图默认合并同类外围企业，保留当前企业、天然气/供电/供热、水务/污水/固废等不同源头服务。局部图不同层级、传入/传出角色不混组。分组保留成员名单和原关系，点击节点展开成员，点击合并连线查看原始端点、商品和强度区间；可一键展开全部。图形分组不参与矩阵、概率、授信或历史数据计算。分组颜色取成员最高风险，不生成虚构的“集团违约概率”；合并线宽仅为平均强度的视觉编码，绝不把权重求和作为新概率。

风险传导默认“关键链路”：取后端已算的前三条主要传入路径、前三个主要传出主体各自最强的路径，保留两段原始端点及平行渠道；同侧同层同类主体可折叠。图形高度随可见列人数缩短。“全部链路”恢复所选类型、层级的完整原图。精简不改变综合风险、授信、下方当前筛选明细；图下注明可见范围与完整范围。合并风险连线显示成员关系数，展开后查看独立净影响，不把不同接收企业的贡献相加解释为一个企业的风险。

压力情景按相对正常情景的综合风险增幅列出前三个主要恶化主体，显示前后风险、百分点增幅和风险等级变化，可点击切换分析。前三名和所有风险等级升级的主体均保持单独节点，使用红色标记和增幅文字，相关主要变化连线加深；不把高基线但风险未上升的企业列为新增恶化。正常情景隐藏恶化卡片。

## 迁移和复现

首次迁移先备份CSV、JSON及SQLite，再在单次数据库事务中新增36个主体的数据版本、替换当前参考数据并保存旧参考表快照。旧版本、审核事件、证明材料均保留；旧未结事项归为历史版本事项，历史列表使用历史版本名称。后续补齐月度参考台账不覆盖企业头版本。重复执行不会覆盖已经发生的业务更新。

当前版本为 `park-v3`。首次重构前原始备份位于 `data/runtime/backups/park-v2-20261025-154157/`；最终v3迁移前备份位于 `data/runtime/backups/park-v3-20261025-160704/`。数据库 `dataset_migrations` 保存迁移标识、文件摘要和此前参考表内容。

```bash
# 生成并校验暂存数据
.venv/bin/python scripts/rebuild_park_data.py
# 明确应用版本迁移，已迁移时保留后续业务更新
.venv/bin/python scripts/rebuild_park_data.py --apply
# 为全新演示库重新生成CSV
.venv/bin/python scripts/generate_demo_data.py
```

重构回归检查覆盖分类、命名、关系角色、交易镜像、供给能力、污水回用边界、派生特征、运行模板、历史保留、迁移幂等、情景差异、A正常与压力结果，以及图谱分区、节点间距和绕行。新建模拟名称不是对旧企业真实身份的更正。
